# JobTrack

A premium dark-first Job Application Tracker.

## Part 1 — Frontend
Built with React, Vite, Tailwind CSS, React Router, Recharts and Lucide React.

## Run
```bash
npm install
npm run dev
```

## Project structure
The current dashboard implementation is preserved in `src/components/dashboard/JobTrackDashboard.jsx`. The surrounding folders are organized for the next application-management and backend phases.

## Roadmap
- Part 1: Frontend UI
- Part 2: Express + MongoDB
- Part 3: JWT authentication + CRUD
- Part 4: Analytics + advanced features
- Part 5: Polish + deployment
